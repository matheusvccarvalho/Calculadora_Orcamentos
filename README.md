# 🚗 Sistema de Orçamento Automotivo

## 📚 Sobre

Sistema desenvolvido para cálculo e gestão de orçamentos automotivos, utilizando como apoio para calculo de porcentagens (10% e 20%) para elaboração nas plataformas Cilia e Audatex.

O projeto tem como objetivo automatizar cálculos, facilitar a visualização dos valores e tornar o processo mais rápido e eficiente.

---

## ⚙️ Funcionalidades

* Cálculo automático de porcentagens
* Interface visual moderna estilo recibo
* Destaque de valores e totais

---

## 🧠 Tecnologias Utilizadas

* Python
* Interface gráfica (GUI)
* Lógica de cálculo personalizada

---

## 🎯 Objetivo

Otimizar o processo de criação de orçamentos, reduzindo erros manuais e aumentando a produtividade.

---

## 🚀 Em evolução

Novas funcionalidades e melhorias visuais estão sendo implementadas continuamente.

---

## 📌 Observação

Projeto desenvolvido com base em necessidades reais do dia a dia no setor automotivo.
